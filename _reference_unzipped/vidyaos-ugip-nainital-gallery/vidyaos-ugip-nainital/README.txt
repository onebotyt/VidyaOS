Open index.html in a modern browser to preview.

Recent refinements:
- NBA Guidelines badge placed at the top of the white login panel.
- Gallery cards feature a light flash/glow animation on hover and keyboard focus.
- Upload Images button allows selecting multiple local image files; these appear in a My Uploads gallery for the current browser session. Uploaded previews are not saved after page refresh and are not sent to a server.

This is a frontend demo. Authentication and external sign-in placeholders require backend/OAuth integration.
