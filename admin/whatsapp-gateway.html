⚙️ Engine Architecture

Session Persistence:
Tokens are saved in backend/whatsapp_session/ using WhatsApp Web LocalAuth. Restarting the server does not log out the connected phone.
Headless Execution:
Uses the pre-installed Playwright Chromium binary in headless mode. Consumes ~70MB RAM with zero extra downloads.
Anti-Spam Safeguards:
Outgoing messages are queued with jittered human delay intervals (200-800ms) to ensure institutional phone accounts remain compliant with WhatsApp usage policies.

🛡️ Fail-Safe Fallback Modes

If the college smartphone loses battery or is disconnected, the system automatically and instantly activates two fallback layers:

1️⃣
Dynamic QR Code: Users scan a live QR code on screen to retrieve the verification code.
2️⃣
Direct wa.me Chat Link: Users tap a 1-click WhatsApp link to message the department dispatch assistant.

✓ Student onboarding never halts, even during power cuts or offline maintenance.
